PLC 气动控制系统
接线原理全解析

基于 X3U-18MT 晶体管输出型 PLC，配合二位五通电磁阀与双作用气缸的典型竞赛装置。从输入信号到气动执行，逐层拆解每一根线的去向与作用。

01 / SYSTEM OVERVIEW

系统架构总览

整个系统采用"弱电控制强电、PLC间接驱动气动"的架构，PLC输出端不直接接电磁阀，而是通过中间继电器KA中转，实现强弱电隔离。

输入侧源型 PNP 接法

公共端 GND 接 0V，开关另一端并联接 DC24V+。按下开关时 X 点得到 24V 高电平，内部 LED 点亮。

输出侧晶体管源型

公共端接 DC24V+，负载另一端接 GND。Y 点输出高电平时负载得电。Y0/Y1 支持高速脉冲输出。

气动侧继电器隔离

PLC 的 Y0 只能输出小电流，通过 KA 中间继电器的常开触点控制电磁阀 YV 线圈，实现强弱电隔离。

03 / PNEUMATIC CIRCUIT

气动回路原理（可动画演示）

二位五通单电控电磁阀控制双作用气缸伸缩。点击按钮观看气流走向和气缸动作，红色为加压气路，灰色为排气。

伸出YV 得电

1口(P) → 4口(A) 通气，压缩空气进入气缸无杆腔（左）
2口(B) → 5口(S) 排气，有杆腔经消声器排气
结果：气缸伸出，到右端触发 SQ1

缩回YV 失电

弹簧复位，1口(P) → 2口(B) 通气，压缩空气进入有杆腔（右）
4口(A) → 3口(R) 排气，无杆腔经消声器排气
结果：气缸缩回，到左端触发 SQ2

05 / WORKFLOW

完整工作流程

从上电到自动循环，每个阶段的输入输出状态和气缸动作。

上电待机

接通24V电源，PLC上电自检。A黄灯亮，气缸默认在缩回位（SQ2被压合），系统等待启动指令。

按下启动 SB1

X0得电，PLC进入运行状态。B绿灯亮、A黄灯灭，Y0输出→KA吸合→YV得电→气缸开始伸出。

气缸伸出

YV得电，无杆腔进气、有杆腔排气，活塞向右运动。到达右极限时磁性开关SQ1触发（X3得电）。

到位延时 / 保持

SQ1触发后，根据工艺要求可能延时一段时间（如1秒），或立即执行下一步。期间气缸保持伸出状态。

气缸缩回

Y0断开→KA释放→YV失电→弹簧复位。有杆腔进气、无杆腔排气，活塞向左运动。到达左极限时SQ2触发（X4得电）。

循环 / 停止

SQ2触发后，若为自动模式则返回第3步继续循环；若按下SB2停止，则完成当前循环后停机，A黄灯亮。

急停ES-1 紧急停止处理

拍下急停后，X5失电（常闭触点断开），PLC应立即执行中断：切断所有输出（Y0~Y3全部OFF），C红灯亮，气缸保持当前位置。急停复位后需按SB2复位才能重新启动。急停必须用常闭触点，这是安全规范——线路断线时等效于急停触发。

06 / NOTES

接线注意事项

技能节比赛评分的细节点，也是实际安全操作的关键。

24V正负极不要接反。GND是负极（0V），DC24V是正极。接反可能烧坏PLC输入点或指示灯。接线前用万用表确认电压。
KA继电器线圈必须并联续流二极管。继电器线圈断开瞬间会产生反向电动势，可能击穿PLC晶体管输出点。二极管阴极接24V+，阳极接Y0侧（反向并联）。
急停ES-1用常闭触点，不要接成常开。常闭接法在断线时也能触发急停，是安全规范。接线后测试：拔下急停的一根线，PLC应报急停。
SQ1/SQ2磁性开关安装位置要准确。装在气缸两端的感应环位置，活塞到位时开关上的指示灯必须亮。用绑带固定后再微调，确保到位可靠触发。
电磁阀3口和5口必须装消声器。不装消声器噪音很大，且排气口容易进灰损坏阀件。消声器要拧紧但不要用力过度导致滑牙。
走线要横平竖直，进走线槽。强弱电分开走，输入线和输出线尽量不要扎在一起。每个端子压接牢固，不留毛刺，线头不超过2mm。线号管方向一致、字迹朝外。
面板元件布局要居中对称。开孔前用尺子和铅笔画线，确保同排元件中心高度一致、间距均匀。急停单独放最左，与其他元件保持30mm以上间距。
电磁阀YV线圈电压确认是DC24V。KA触点容量要满足YV线圈电流要求。接线后先不通气，单独测试电磁阀换向是否正常，再通气测试气缸。
07 / PLC PROGRAM

PLC 程序设计（梯形图 + 指令表）

根据灯逻辑（待机=黄A、运行=绿B、停止=红C）和气缸自动往返控制要求编写的完整梯形图程序，适用于信捷X3U系列PLC。

IO分配程序使用的软元件一览
X0 = SB1 启动按钮（常开）
X1 = SB2 停止按钮（常开）
X3 = SQ1 伸出到位（常开）
X4 = SQ2 缩回到位（常开）
X5 = ES-1 急停（常闭，正常时接通）
Y0 = KA继电器→电磁阀YV
Y1 = A灯 黄色（待机）
Y2 = B灯 绿色（运行）
Y3 = C灯 红色（停止）
M0 = 运行标志（辅助继电器）
T0 = 伸出到位延时（100ms×10=1s）
(* ===== X3U-18MT 气缸自动往返控制程序 ===== *) (* 灯逻辑：待机=Y1黄 运行=Y2绿 停止=Y3红 *) Network 1 // 运行自锁（启保停） LD X0 // SB1启动按钮 OR M0 // 自锁触点 ANI X1 // SB2停止按钮（常闭逻辑） ANI X5 // 急停常闭，正常接通 OUT M0 // 运行标志 Network 2 // 待机黄灯 Y1 = 非运行 AND 急停正常 LDI M0 // 非运行 AND X5 // 急停正常 OUT Y1 // A黄灯亮 Network 3 // 运行绿灯 Y2 = 运行中 LD M0 OUT Y2 // B绿灯亮 Network 4 // 停止红灯 Y3 = 急停按下 OR 停止按下 LDI X5 // 急停按下（X5断开→LDI接通） OR X1 // 停止按钮按下 OUT Y3 // C红灯亮 Network 5 // 气缸伸出 Y0 = 运行 AND 在缩回位 AND 未到延时 LD M0 // 运行中 AND X4 // SQ2缩回到位 ANI T0 // 延时未到 OUT Y0 // KA吸合→YV得电→气缸伸出 Network 6 // 伸出到位延时1秒 LD X3 // SQ1伸出到位 OUT T0 // K10 延时1秒（100ms×10） // 延时到→T0常闭断开→Y0失电→气缸缩回 // 缩回到位SQ2接通→Y0再次得电→循环 (* ===== 程序结束 ===== *)
Network 1运行自锁

经典启保停电路。按下SB1(X0)，M0得电并通过自身常开触点自锁保持。按下SB2(X1)或拍下急停(X5断开)，M0失电，系统停止。急停用常闭触点串联，保证断线时也能停止。

Network 2待机黄灯 Y1

非运行(M0常闭) AND 急停正常(X5常开接通)时，Y1输出，黄灯A亮。表示系统上电就绪、等待启动。运行中或急停时黄灯灭。

Network 3运行绿灯 Y2

M0接通（运行中）时，Y2输出，绿灯B亮。直接跟随运行标志，最直观。

Network 4停止红灯 Y3

急停按下(X5常闭→LDI接通) OR 停止按钮按下(X1)时，Y3输出，红灯C亮。注意：SB2是点动按钮，按下瞬间红灯亮，松开后如果M0已断开则系统回到待机黄灯状态。

Network 5气缸伸出 Y0

运行(M0) AND 缩回到位(SQ2/X4) AND 延时未到(T0常闭)时，Y0输出→KA吸合→YV得电→气缸伸出。这是自动循环的核心：只要在运行状态且气缸在缩回位，就自动伸出。

Network 6到位延时 T0

气缸伸出到位SQ1(X3)触发后，定时器T0开始计时（K10=1秒）。1秒后T0常闭触点断开→Y0失电→YV失电→气缸缩回。缩回到位后SQ2接通，Y0再次得电，如此循环往复。需要改停留时间就改K值（K20=2秒）。

工作循环完整时序

① 上电 → 黄灯亮(待机)，气缸在缩回位(SQ2通)
② 按SB1 → M0自锁 → 绿灯亮、黄灯灭 → Y0输出 → 气缸伸出
③ 伸出到位 → SQ1通 → T0计时1秒
④ 延时到 → T0常闭断 → Y0断 → 气缸缩回
⑤ 缩回到位 → SQ2通 → Y0再次输出 → 重复②~⑤（自动循环）
⑥ 按SB2 → M0断 → 绿灯灭、红灯亮 → 完成当前动作后停在缩回位 → 黄灯亮(待机)
⑦ 拍急停 → M0断、所有输出断 → 红灯亮 → 气缸保持当前位置
